P0 Prototype — Sortable Listings table headers

Exact markup/classes from listing-list.tsx's <thead> and row cells (checkbox column, title cell with its photo icon / EbayScanBadge / NonWorkingBadge, status, price cells, IdentifyPartsStatusBadge, Accept/Reject buttons), unchanged. The only new piece is each of the 7 data-bearing headers becoming a clickable button with a lucide ArrowUp/ArrowDown indicator (same icon set as the app's existing Image/ChevronDown icons) next to the active field's label.

Dashed box = prototype annotation only. Click any of Title / Source / Status / Asking Price / Expected Resale / Difference / Identify Parts: an inactive header becomes the active sort field ascending; clicking it again flips to descending; clicking a different header replaces the active field outright (the old column's arrow disappears) — the 7 sample rows below actually reorder to demonstrate it. The leading checkbox header and trailing actions header are inert, exactly like in the real table. Real sorting (per the plan) runs server-side across the whole filtered dataset, not just a page — this prototype only has 7 sample rows, so the reordering here is plain client-side JS over that small fixed array, standing in for that real behavior.
