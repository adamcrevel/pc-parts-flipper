Goal

On the Listings page's create/edit form (ListingForm / ListingFields, shown inline when a row is clicked or a new Listing is being created), two changes to the existing field layout: 1. An "Open Link" button appears immediately to the left of the existing Listing URL input. Clicking it opens that URL in a new browser window/tab. The Listing URL input itself is untouched — same label, same element, same editability, same validation — this is a new control placed next to it, not a replacement for it (the user explicitly reverted an earlier "make the URL itself a clickable link" direction in favor of this). 2. The Source field becomes read-only once a Listing already exists (editing a saved Listing) — it still shows which Source the Listing came from, but the user can no longer change it from this form. It stays a normal, editable selector while creating a brand-new Listing, since a Source must still be chosen to create one in the first place (Assumption A1).

Requirements

  • 1The inline edit form's Listing URL field keeps its current label, input element, value binding, and validation exactly as they are today — no part of the existing Listing URL field changes.
  • 2A new "Open Link" button appears immediately to the left of the Listing URL input, in the same row.
  • 3Clicking "Open Link" opens the Listing's current URL value in a new browser window/tab (not the current tab), without submitting or otherwise altering the form.
  • 4The "Open Link" button is disabled when the Listing URL field is empty — there is nothing to open, and the previous behavior (no link, no button) must not regress into a dead click target.
  • 5The Source selector is disabled (read-only) whenever the form is editing a Listing that already exists on the server — the currently-selected Source still renders, visibly, but cannot be changed through this control.
  • 6The Source selector remains a normal, enabled, editable selector while creating a new Listing (no existing saved record yet) — Requirement 5 never blocks choosing a Source for a brand-new Listing.
  • 7Every other field, button, and existing validation/behavior on this form (title, description, asking price, listing date, acquisition fees, Expected Parts editor, photo upload, Save/Cancel) is unchanged.
